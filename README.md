# ts-barrel-transformer

A TypeScript transformer and webpack loader for tree-shaking barrel file imports. Works with ts-loader, webpack, and rspack.

## Motivation

This project is inspired by [Next.js `optimizePackageImports`](https://nextjs.org/docs/app/api-reference/config/next-config-js/optimizePackageImports), which automatically optimizes barrel file imports in Next.js applications.

If you're using **Next.js**, you can simply configure it in `next.config.js`:

```js
// next.config.js
module.exports = {
  experimental: {
    optimizePackageImports: ['antd', '@mui/material', 'lodash-es']
  }
}
```

However, if you're using **webpack/rspack with ts-loader** (without Next.js), you need this transformer to achieve the same optimization.

## Problem

Barrel files (index.ts that re-exports from multiple modules) break tree-shaking:

```ts
// my-lib/index.ts (barrel file)
export { Button } from './button'
export { Icon } from './icon'
export { Modal } from './modal'
// ... 100+ more exports

// Your code - only needs Button, but webpack bundles everything
import { Button } from 'my-lib'
```

This transformer rewrites imports to only include what you actually use.

## Installation

```bash
bun add ts-barrel-transformer -D
# or
pnpm add ts-barrel-transformer -D
```

## Usage

### With ts-loader (webpack/rspack)

```ts
// webpack.config.ts
import { createNamedImportTransformer, createBarrelLoaderRule } from 'ts-barrel-transformer'

export default {
  module: {
    rules: [
      // 1. Add the barrel loader rule
      createBarrelLoaderRule(),

      // 2. Configure ts-loader with the transformer
      {
        test: /\.tsx?$/,
        use: {
          loader: 'ts-loader',
          options: {
            getCustomTransformers: () => ({
              before: [
                createNamedImportTransformer({
                  packages: ['antd', '@mui/material', 'lodash-es']
                })
              ]
            })
          }
        }
      }
    ]
  }
}
```

## How It Works

1. **Transformer Phase**: Rewrites imports from configured packages:
   ```ts
   // Before
   import { Button, Icon } from 'antd'

   // After (internal representation)
   import { Button, Icon } from '__barrel_optimize__?names=Button,Icon!=!antd'
   ```

2. **Loader Phase**: Intercepts the rewritten imports and generates optimized exports:
   ```ts
   // Generated by loader - only exports what you need
   export { Button } from 'antd/es/button'
   export { Icon } from 'antd/es/icon'
   ```

## API

### `createNamedImportTransformer(config)`

Creates a TypeScript transformer for rewriting imports.

```ts
interface TransformerConfig {
  packages: string[]  // Package names to optimize
}
```

### `createBarrelLoaderRule(options?)`

Creates a webpack rule for the barrel loader.

```ts
interface BarrelLoaderRuleOptions {
  cacheDir?: string  // Optional cache directory
}
```

### `analyzeBarrelFile(source, filename)`

Analyzes a file to determine if it's a barrel file.

```ts
interface BarrelAnalysisResult {
  isBarrel: boolean
  exportMap: ExportMap
  wildcardExports: string[]
  directives: string[]  // "use client", "use server"
}
```

### `clearCache()`

Clears the internal analysis cache.

## Supported Patterns

- Named imports: `import { A, B } from 'lib'`
- Aliased imports: `import { A as AliasA } from 'lib'`
- Re-exports: `export { A } from './a'`
- Wildcard re-exports: `export * from './utils'`
- Namespace re-exports: `export * as utils from './utils'`
- Directives: `"use client"`, `"use server"`

## Not Transformed

- Default imports: `import Lib from 'lib'`
- Namespace imports: `import * as Lib from 'lib'`
- Side-effect imports: `import 'lib'`
- Packages not in config
